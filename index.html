Bridge

Featured · Startup Co-Founder and Full-Stack Developer · Hackathon project, deployed and live

A peer-to-peer donation platform that connects people with surplus food and clothing to nearby people who need it, with volunteer drivers handling delivery. No centralized drop-off, no fixed hours.

  • Designed a three-role flow where helpers post donations, people in need browse and request items, and drivers accept nearby deliveries on demand. Each match gets a live delivery tracker and a shared in-app chat, so no one has to exchange phone numbers.
  • Removed the biggest friction in donating by letting helpers photograph an item while Gemini Vision (gemini-2.5-flash) auto-generates a structured list of item names, quantities, and sizes, turning a 2-minute chore into a 10-second photo.
  • Built with a React 18 + TypeScript front end on Vite, a FastAPI back end on Google Cloud Run (Python 3.11), a Firestore database, Firebase Auth, Storage, and Hosting, Leaflet and OSRM for maps and routing, Nominatim for geocoding, and CI/CD through GitHub Actions.
