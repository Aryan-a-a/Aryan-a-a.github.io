Bridge — Co-Founder & Full-Stack Developer

Featured · Startup Hackathon project, deployed and live

A peer-to-peer platform that connects people with surplus food and clothing to nearby people who need it, with volunteer drivers handling delivery — no centralized drop-off, no fixed hours.

  • Three roles keep the flow simple: helpers post donations, people in need browse and request items, and drivers accept nearby deliveries on demand. Each match gets a live delivery tracker and a shared in-app chat, so no one has to exchange phone numbers.
  • Cut the biggest friction in donating — listing what you have — by letting helpers photograph an item and using Gemini Vision (gemini-2.5-flash) to auto-generate a structured list of item names, quantities, and sizes. Turns a 2-minute chore into a ~10-second photo.
  • Stack: React 18 + TypeScript + Vite front end; FastAPI on Cloud Run (Python 3.11) back end; Firestore database; Firebase Auth (Google sign-in), Storage, and Hosting; Leaflet + OSRM for maps and routing, Nominatim for geocoding; CI/CD via GitHub Actions.
